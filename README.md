# EnMed Interactive Engineering Courses (prototype)

Interactive, browser-based courses that teach engineering fundamentals to Texas A&M EnMed (MD + MEng) students.

- `index.html` – landing page listing all courses
- `ecg-biosignals-101.html`
- `biomechanics-biomaterials-101.html`
- `hemodynamics-biofluids-101.html`

Each course is a single self-contained HTML file. Format inspired by the open tutorial
[EEG & Signal Processing (Neuro Signals 101)](https://judepj.github.io/neuro-signals-101/). Content is a prototype under faculty review.
